# CyberShield - Demo Statis (GitHub Pages)
Versi demo online tanpa PHP/MySQL: semua data disimpan di browser (localStorage).
Tampilan dan fitur sama dengan versi PHP; mesin firewall dijalankan oleh `assets/mock-api.js`.

## Cara upload ke GitHub Pages
1. Upload isi folder ini (`index.html` dan folder `assets/`) ke repository, di root atau subfolder.
2. Settings -> Pages -> Branch `main` -> Save.
3. Buka linknya, mis. `https://<username>.github.io/<repo>/`.

> Versi ini hanya untuk demo online. Untuk pengumpulan soal, pakai versi PHP + MySQL (folder `cybershield`).
